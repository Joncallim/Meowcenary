# Core Loop

## Run Loop

1. Player enters arena.
2. Enemies spawn according to the active spawn curve.
3. Player moves while weapons fire automatically.
4. Enemies drop XP and currency.
5. XP triggers level-up upgrade choices.
6. Build strength escalates until victory or defeat.
7. Run rewards feed meta progression.

## Decision Points

The player should make decisions through:

- Movement and positioning.
- Upgrade choice.
- Weapon merge priority.
- Permanent upgrade selection.

The player should not need precise aim, combo inputs, or fast reactions to enjoy the game.
