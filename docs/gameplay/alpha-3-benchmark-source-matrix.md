# Alpha 3 Mobile Benchmark Source Matrix

**Checked:** 2026-09-03.

This file records the public evidence behind `alpha-3-engagement-benchmark.md`. Google Play download badges are **lower-bound tiers**, not exact lifetime download counts.

The benchmark is intentionally broader than “games we like.” Primary weight goes to mobile titles with the largest visible Android scale in or immediately adjacent to the one-hand roguelite/survivor space. Smaller-but-influential titles are used for specialist mechanic lessons.

# 4. Cross-reference conclusions

The recurring high-value patterns across the benchmark are:

1. **Controls are understood almost immediately.**
2. **Automatic combat still leaves movement/positioning and build choices to the player.**
3. **Something meaningful changes frequently.**
4. **Power becomes visually obvious, not only numerically higher.**
5. **Characters/heroes create different run identities.**
6. **Build choices combine into a describable fantasy.**
7. **Enemy pressure escalates and changes shape.**
8. **Bosses/chapters/biomes punctuate progression.**
9. **The path into another run is short.**
10. **Large content catalogs help only when their entries are genuinely differentiated.**

These ten patterns inform Meowcenary's product acceptance.

They do **not** justify:

- energy systems;
- daily login pressure;
- ads;
- random paid power;
- gacha;
- five-plus currencies;
- live-event grind;
- copied UI layouts;
- copied hero/item/evolution content.

# 5. Meowcenary-specific translation

| Benchmark pattern | Meowcenary implementation target |
| --- | --- |
| immediate one-hand play | move + auto-fire + one active ability |
| frequent decisions | four-card level choices + weapon pickup/merge + objective positioning |
| visible snowball | projectile count/pierce/spread/rate/traits + stronger weapon rack |
| hero identity | eight distinct Mercenaries with active abilities and starting-family identity |
| build fantasy | family-scoped cards + Equipment Set thesis + Gunsmith traits |
| pressure change | 20–30s encounter-layer cadence where appropriate |
| biome identity | Junkyard + Forge Foundry use the same Arena system but play/look differently |
| boss punctuation | Scrap Crusher / Forge Warden immediate boss fights with escalating adds/phases |
| fast replay | Next Contract / Retry / Adjust Loadout directly from results |
| long-term reason to replay | chosen fabrication, Equipment sets, Gunsmith engineering, mastery, achievements, Compendium |

The resulting target is deliberately smaller and cleaner than the most monetised references: **depth from interaction between systems, not retention-system count.**
