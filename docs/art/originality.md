# Originality Guardrails

Meowcenary can be inspired by broad genre patterns, but must not copy another game's protectable expression.

## Avoid

- Reference game names in marketing copy.
- Copying character designs, enemy silhouettes, weapon icons, UI layout, animations, sound effects, or economy numbers.
- Using the exact merge or reward presentation from any reference game.

## Prefer

- Junkyard, workshop, and improvised-gear motifs.
- Original characters and factions.
- Original enemy families.
- Original weapon names and upgrade names.
- UI layouts designed around browser and mobile comfort.

## Working Rule

Use references for product learning, then describe Meowcenary in its own vocabulary before implementation.
