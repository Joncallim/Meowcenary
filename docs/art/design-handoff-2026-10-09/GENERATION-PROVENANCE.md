## Tabby directional study

Prompt:

Create one rigorous 4-column by 4-row game sprite DIRECTIONAL EXPLORATION sheet on a truly transparent background. Exactly sixteen separate poses of THE SAME original canonical character SCRAP TABBY from Meowcenary. This is NOT a roster, NOT colour variants. Subject identity must remain identical throughout: compact short upright amber-and-cream scrapyard feline, square head, strong triangular ears with one anatomical ear notch, short striped tail held close, small teal neckerchief, round small tin-lid shoulder fixture, little utility belt. Friendly practical confidence. No held weapons or changeable armor, no scenery, no captions, no letters, no gridlines, no shadows. Direction columns left to right are RIGHT PROFILE, LEFT PROFILE, FRONT facing viewer, BACK facing away. Preserve notch and costume anatomy as real rotated views, not random redesigns. Rows top to bottom: row 1 relaxed planted IDLE; row 2 RUN first stride with clear separated feet; row 3 RUN alternate stride; row 4 natural unarmed grip-pose with paws ready for separately composited weapon, no weapon itself. Each cell equal size with character centered at identical floor baseline and generous transparent margins, full ears/tail visible. Style is deliberately native 48x48-feasible pixel art: hard square pixels, near-black #0a0f14 1-pixel outline, broad deliberate clusters, very few flat colors, cream/rust/teal/brass, no gradients, no anti-aliased outline, no soft furry painterly texture, no glossy highlights, no microdetail. Use a clean chunky low-resolution pixel grid uniformly throughout, shown enlarged with crisp nearest-neighbor squares. Front/back are genuine anatomical views of this same compact Tabby. At least half each cell is useful transparent separation so poses never touch. All sixteen figures same scale.

Outcome: art/tabby-direction-study-v1.png. Shoulder/notch continuity and native-pixel/anchor quality failed acceptance; useful direction reference only.

## Pickup family

Prompt:

Create one small-game PICKUP ART EXPLORATION sheet, three rows by four columns on genuine transparent background. This is an original scrapyard pixel-survivor game, Meowcenary. Row 1: SAME tiny XP salvage-energy mote in four subtle shimmer frames. Tall narrow seed-like capsule, cream center with sky-blue upper shard and teal lower edge, dark metal side casing; NOT a rounded orb, NOT a coin, NOT glossy jewel loot. Row 2: SAME low asymmetric SCRAP bundle in four subtle glint frames: one large silver bolt/nut, bent rusty plate and loop of wire/tyre, physical salvaged currency, near-black outline, no cyan, no coin. Row 3: SAME squat SALVAGE CACHE in four tiny beacon/glint frames: broad dark-gunmetal hard-case lid, off-center cream/brass latch, reinforced rust corners, one tiny teal light, not fantasy treasure chest, not ammunition badge. Each item remains centered and identical silhouette across all four frames; vary only a restrained one-pixel-style highlight or shutter, no bounce, no rotation, no opening sequence, no text. All twelve items completely separate, aligned equal cells, large empty transparent gutters. Designed to be deliberately reconstructed at native 16x16 for XP and 20x20 for scrap/cache: few broad hard-edged pixel clusters, clean black outline, at most 8 flat colors per item, crisp discrete square pixels, no painterly texture, no gradients, no antialiasing, no drop shadows, no floating glow, no UI plate or frame. Enlarged nearest-neighbor low-resolution art look. Objects must be mutually unmistakable in black silhouette and grayscale.

Outcome art/pickup-family-exploration.png. Independent review found XP still crystalline rather than clearly manufactured and the cache latch centered rather than off-center. These are explicit cleanup directions for native authoring. Four illustrated variants do not prove an accepted four-frame native animation.
