# Epic 16 Concept Generation Record

The visual identity production board in this directory was generated with
Codex's built-in image generation tool. It is an art-direction reference only:
it is not a runtime sprite, a Pixelorama source, a sprite sheet, or a tracing
target.

## Visual identity production board

```text
Use case: stylized-concept
Asset type: cohesive pixel-inspired production design board for a mobile
top-down action game, grounded in Meowcenary's existing Scrap Tabby and
junkyard prop direction.

Primary request: establish one original visual language for Epic 16 across
three improvised weapon families, their tier progression and held silhouettes,
family-readable projectiles, four pickup categories, and the Junkyard Lot
environment kit.

Weapons: show Scrap Pistol, Can-Drum SMG, and Bolt Shotgun as three rows. Each
row progresses from T1 to T3 through a stronger silhouette: T1 is compact and
rough, T2 adds one readable functional module, and T3 is broader and more
confident without becoming realistic military hardware. Include one small
right-facing held silhouette for each family beside a neutral cream cat bust.

Projectiles: show a cyan pistol slug, a sharp teal SMG spark, and a warm-orange
shotgun pellet cluster. For each family, show small-to-large motion/readability
examples that preserve a compact fixed center.

Pickups: show the established blue XP mote, a silver-and-rust scrap bundle, a
purple-and-gold junk chest, and a gold weapon crate with a clear dark weapon
mark. Each pickup must have a different silhouette before color is considered.

Environment kit: show a dark warm-gray floor tile, patchwork boundary wall,
non-colliding tyre pile, crate, engine block and scrap heap, ground-level oil
stain and warning sign, and two visibly substantial collidable landmarks. Add
one top-down arena composition example with a clear central breathing space,
sparse colliders, boundary framing, corner landmarks, and non-colliding clutter.

Style and palette: crisp chunky pixel-inspired 2D game art, near-black outline,
flat high-contrast clusters, gunmetal and charcoal foundation, rust orange and
worn leather, teal/cyan energy, warm cream highlights, purple/gold chest accent.
Cute, friendly and characterful rather than gritty. Three-quarter top-down
view for objects and a true top-down read for the arena.

Composition: one 3:2 landscape board on a dark navy studio background, arranged
in clean production rows with compact labels. Preserve breathing room around
each silhouette and keep the arena example large enough to judge navigation.

Constraints: original junkyard/workshop/improvised-gear vocabulary only. Do not
copy or reference another game's characters, weapons, UI, icons, pickups,
layouts or animation timing. No photorealism, smooth vector rendering,
gradients, real-world gun branding, military insignia, gore, watermark, or
claim that the board contains production-ready pixels. Prioritize readability
at Meowcenary's 390x844 phone canvas over decorative detail.
```

## Selection record

The selected board is
[`visual-identity-production-board.png`](visual-identity-production-board.png).
It was selected because it provides one consistent silhouette and palette
system across all missing Golden Run categories while preserving the existing
actor direction. In particular:

- the three weapon families differ by mass and outline, not just color;
- each tier reads as an additive silhouette step;
- pistol, SMG, and shotgun projectiles remain distinct when tiny;
- all four pickup categories have different outer shapes; and
- the arena example demonstrates rich non-colliding dressing around sparse,
  obvious collidable landmarks.

Production builders must reinterpret and simplify the board at the exact frame
sizes in [`../../epic-16-visual-design.md`](../../epic-16-visual-design.md).
They must not crop, trace, or ship any part of the generated board.
