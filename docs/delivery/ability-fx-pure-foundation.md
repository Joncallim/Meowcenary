# Ability FX pure foundation

This bounded foundation starts from current main `4f79` and provides pure recipe
validation, immutable presentation plans, and cosmetic frame selection for #241.
It is nonshipping: the existing production ability catalog, runtime behavior,
resources, and assets remain unchanged.

The tests enrich all eight existing ability definitions with synthetic recipes
and atlas metadata, then add a ninth fixture to exercise the same generic path.
These fixtures prove the data contract, immutable snapshots, mechanic-derived
facts, timing boundaries, reduced-motion selection, and selected-atlas budget
calculation. They do not provide accepted production art or demonstrate its
visual quality. Mechanical area effects retain their authoritative radius;
self effects expose only a decorative diameter derived from `visualRadius`.

The enriched definition boundary requires `presentation.fx`. It does not make
FX optional in the eventual production contract. The narrow lookup can describe
an `effect` binding without expanding the shared art-kind registry yet.

The complete production cutover remains deferred:

- All eight production recipes and accepted activation and sustained art.
- Actual atlas exports, global texture-budget verification, and generic registry
  and validator support for the `effect` kind.
- Resource-loader dependency closure and selected-ability loading.
- Renderer integration, authoritative effect lifecycle, and reduced-motion UI.
- Save and persistence integration and equipped-ability UI integration.
- Production art validation, browser acceptance, and visual review.

The plan validates and counts only the atlas pages referenced by its selected
recipe. Global asset-budget compliance still needs validation against the real
production resource graph. No resource manifests, loader code, renderers, save
boundaries, live controls, or production assets change in this foundation.
